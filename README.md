# PayPilot AI – Autonomous Business Finance Agent

PayPilot AI is an autonomous finance agent that helps businesses monitor,
analyze, and act on their financial data.

> Status: Initial project scaffold — no application logic implemented yet.

## Tech Stack

- **Frontend:** React, Recharts
- **Backend:** FastAPI (Python)
- **Database:** MongoDB Atlas
- **AI:** Gemini API
- **ML:** Python, scikit-learn
- **Agent workflow:** LangGraph / custom agent orchestration
- **Deployment:** Render

## Project Structure

paypilot-ai/
